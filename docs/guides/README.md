# Guides

Task-shaped help for the scanner programs. Remember: don't
deploy these as services.

| Guide | Use it when |
|---|---|
| [Operate](operate.md) | You're reading exit codes, stderr, and result pages from a run |
| [Troubleshoot](troubleshoot.md) | Eshu refuses the work, or go-reachability won't fetch |
| [Seed](seed.md) | You're installing a program into a runtime directory |
| [Release](release.md) | You're publishing images core will pin by digest |

For the ideas behind these guides, see
[concepts](../concepts/README.md). For every request key,
see [reference](../reference/README.md).
